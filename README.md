# Emmanuel W. Wakhongola — Portfolio

A personal portfolio website for Emmanuel W. Wakhongola, a Mathematics & CS student building intelligent, secure, and user-friendly systems at the intersection of AI, security, and networks.

## 🌐 Live Site

The portfolio is deployed via **GitHub Pages**:  
[https://wangilawakhongola.github.io/MyPortfolio/](https://wangilawakhongola.github.io/MyPortfolio/)

## 📋 Sections

- **About** — Background, education, and what drives the work
- **Experience** — Professional and academic experience timeline
- **Skills** — Technical skills across AI/ML, networking, security, and software development
- **Projects** — Highlighted personal and academic projects
- **CV** — Downloadable resume (PDF)
- **Contact** — Email, GitHub, WhatsApp, and other contact channels

## 🛠️ Tech Stack

- Pure **HTML / CSS / JavaScript** — no frameworks, no build step
- Hosted on **GitHub Pages** via the `main` branch
- Custom typewriter animations, dark/light theme toggle, and role-based landing page

## 🚀 Deployment

Pushes to `main` automatically deploy to GitHub Pages via the workflow in `.github/workflows/static.yml`.
